My work centers on **Agentic AI**, multi-agent coordination, algorithmic optimization, and scalable backend architectures. Beyond code, I write extensively on human focus and computational stress systems.

- 💼 **Current Role**: UI/UX Design Intern – WizzyBox Career Accelerator Program (**WizzyBox Private Limited**).
- 🤖 **Current Focus**: Multi-agent fleet recovery, constraint-based greedy scheduling, and Groq LPU inference.
- 🎓 **Research**: Published author in **IJCRT** on *Tournament Management Agent Using Agentic Artificial Intelligence*.
- 📚 **Author**: Published **2 books** globally on **Amazon KDP** exploring digital focus & computational physics of anxiety.
- 📍 **Location**: Mysuru, Karnataka, India (Available for Remote / Hybrid Internships).
